## yt-dlp 初期采集验证（历史试跑）

2026-10-24 使用 yt-dlp 2026.10.21、官方 EJS 组件及本机 Node 核验 Alan 原视频。返回标题、原发布者 Alan Shao、YouTube 发布日期 2026-10-09、时长 15749 秒，无可下载中英文字幕。B 站元数据与 YouTube 分别记录，不抹平跨平台时间差异。

公开视频的音频可以实际取得。完整音频约 205 MiB，下载过程中保留了开头部分；本轮从已下载部分用 FFmpeg 截出原视频 0–120 秒音频，验证转写入口。**这不代表下载或转写完成了整场采访。** 采集与片段记录保存在 `.open-mentor/media/sun-alan-video/`，不随开源包分发。

用本地 faster-whisper 1.2.1、Whisper tiny 模型在该样本上实际产出 31 段时间戳文字。转写结果保持 `pending`、`speaker=null`，明确只覆盖输入音频；本轮样本的原片偏移为 0。tiny 仅用于验证流程，结果未经逐句听辨，不作为知识库的已核验原话。

实测发现 faster-whisper 1.2.1 直接调用 PyAV 19.0.2 解码时出现 `metadata_errors` 参数不兼容。转写入口改为由 FFmpeg 统一解码，传入波形数组后成功完成本地推理；没有修改第三方包源码或放宽来源核验。
